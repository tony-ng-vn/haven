# Euno MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a local Convex + Vite/React "human CRM" where a logged-in user searches or adds a person, records an optional link plus free-text context, saves, and loops back to search -- a search layer to find back the people you met in life.

**Architecture:** Convex owns auth (Password provider), the database, and four query/mutation functions, all scoped to the logged-in user. A Vite + React frontend renders three surfaces: a login gate, a search/add screen, and a person-detail screen. No separate server. Search is Convex's built-in full-text index on the person's name.

**Tech Stack:** TypeScript, Convex, Convex Auth (`@convex-dev/auth`, Password provider), Vite, React 19, Vitest + `convex-test` for backend tests.

## Global Constraints

- Project root: `Euno/euno-app` (its own git repo, already initialized).
- Output is ASCII only: no emoji, em-dash, en-dash, ellipsis character, or curly quotes anywhere -- code, comments, or commits. Use `->`, `--`, `...`, straight quotes.
- Every person row is owned by exactly one user (`userId`). Every query and mutation resolves the caller via `getAuthUserId(ctx)` and operates only on that user's rows. A caller can never read or mutate another user's person.
- Auth method is the Convex Auth Password provider (email + password). No external email service; no email verification step.
- Commits follow Conventional Commits (`type(scope): description`), imperative, lowercase, no trailing period.
- Design direction is Apple-inspired: calm, content-first, generous whitespace, system font stack, soft layered surfaces, subtle motion, light + dark via `prefers-color-scheme`. The search box and the person are the heroes.
- Out of scope (do not build): delete person, Apple Contacts import, fuzzy/semantic search, append-only note history.

### Task 2: Define the `people` table and its indexes

**Files:**
- Modify: `convex/schema.ts`

**Interfaces:**
- Produces: a `people` table with fields `userId: Id<"users">`, `name: string`, `link?: string`, `context?: string`, `updatedAt: number`; a `by_user` index on `["userId"]`; and a `search_name` search index on `name` filtered by `userId`. Convex's built-in `_creationTime` serves as the creation timestamp (so no separate `createdAt` field -- this is the idiomatic Convex equivalent of the spec's `createdAt`, preserving the "creation + last-touched timestamps" intent without a redundant column). - [ ] **Step 1: Add the table to the schema**

```ts
import { defineSchema, defineTable } from "convex/server";
import { v } from "convex/values";
import { authTables } from "@convex-dev/auth/server";

export default defineSchema({
  ...authTables,
  people: defineTable({
    userId: v.id("users"),
    name: v.string(),
    link: v.optional(v.string()),
    context: v.optional(v.string()),
    updatedAt: v.number(),
  })
    .index("by_user", ["userId"])
    .searchIndex("search_name", {
      searchField: "name",
      filterFields: ["userId"],
    }),
});
```

```ts
import { mutation, QueryCtx, MutationCtx } from "./_generated/server";
import { v } from "convex/values";
import { getAuthUserId } from "@convex-dev/auth/server";

// Guidelines forbid `any` for ctx; use the proper context union.
async function requireUser(ctx: QueryCtx | MutationCtx) {
  const userId = await getAuthUserId(ctx);
  if (userId === null) {
    throw new Error("Not signed in");
  }
  return userId;
}

export const addPerson = mutation({
  args: { name: v.string() },
  returns: v.id("people"),
  handler: async (ctx, args) => {
    const userId = await requireUser(ctx);
    const name = args.name.trim();
    if (name === "") {
      throw new Error("Name is required");
    }
    return await ctx.db.insert("people", {
      userId,
      name,
      updatedAt: Date.now(),
    });
  },
});
```

- [ ] **Step 3: Write the minimal implementation**

```ts
export const searchPeople = query({
  args: { query: v.string() },
  handler: async (ctx, args) => {
    const userId = await requireUser(ctx);
    const term = args.query.trim();
    if (term === "") {
      return await ctx.db
        .query("people")
        .withIndex("by_user", (q) => q.eq("userId", userId))
        .order("desc")
        .take(20);
    }
    return await ctx.db
      .query("people")
      .withSearchIndex("search_name", (q) =>
        q.search("name", term).eq("userId", userId),
      )
      .take(20);
  },
});
```

```ts
export const getPerson = query({
  args: { id: v.id("people") },
  handler: async (ctx, args) => {
    const userId = await requireUser(ctx);
    const person = await ctx.db.get("people", args.id);
```

```ts
export const updatePerson = mutation({
  args: {
    id: v.id("people"),
    link: v.optional(v.string()),
    context: v.optional(v.string()),
  },
  returns: v.null(),
  handler: async (ctx, args) => {
    const userId = await requireUser(ctx);
    const person = await ctx.db.get("people", args.id);
    if (person === null || person.userId !== userId) {

    }
    await ctx.db.patch("people", args.id, {
      link: args.link,
      context: args.context,
      updatedAt: Date.now(),
    });
    return null;
  },
});
```

- [ ] **Step 1: Build the component**

`src/SearchAdd.tsx`:

```tsx
import { useQuery, useMutation } from "convex/react";
import { useState } from "react";
import { api } from "../convex/_generated/api";
import type { Id } from "../convex/_generated/dataModel";

export function SearchAdd({ onOpen }: { onOpen: (id: Id<"people">) => void }) {
  const [query, setQuery] = useState("");
  const results = useQuery(api.people.searchPeople, { query }) ?? [];
  const addPerson = useMutation(api.people.addPerson);

  const trimmed = query.trim();
  const hasExact = results.some(
    (p) => p.name.toLowerCase() === trimmed.toLowerCase(),
  );

  return (
    <div className="search-add">
      <input
        className="search-box"
        placeholder="Search a name, or type a new one"
        value={query}
        onChange={(e) => setQuery(e.target.value)}
        autoFocus
      />
      <ul className="results">
        {results.map((p) => (
          <li key={p._id}>
            <button className="result-row" onClick={() => onOpen(p._id)}>
              {p.name}
            </button>
          </li>
        ))}
      </ul>
      {trimmed !== "" && !hasExact && (
        <button
          className="add-button"
          onClick={async () => {
            const id = await addPerson({ name: trimmed });
            onOpen(id);
          }}
        >
          Add "{trimmed}"
        </button>
      )}
    </div>
  );
}
```
